# Panoramic Image Stitching Desktop Tool

A desktop application built with **Electron.js**, **React.js**, **Adobe React Spectrum**, **Tailwind CSS**, and **OpenCV.js** for stitching multiple images into seamless Cylindrical and Spherical panoramas.



## Features
- **Supported Formats:** JPEG, PNG, AVIF (normal and HDR).
- **Projections:** Cylindrical and Spherical coordinate warping.
- **Interactive Viewport:** Mouse drag-panning, continuous zoom scaling, and rotational matrix controls.
- **Export:** Save stitched outputs directly via native OS dialog.
